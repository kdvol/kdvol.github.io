수집 안내

순살브리핑 웹사이트(soonsal.com)가 처리하는 정보를 적어둡니다.

처리하는 정보

  • 익명 번호 — 브라우저에 무작위로 만든 번호. 같은 브라우저가 다시 왔는지 구분합니다
  • 이용 기록 — 본 페이지·스토리, 읽은 정도와 시간, 들어온 경로(검색·SNS 등), 글 사이 이동
  • 반응 — 👍🤔🔥 버튼, 공유·코멘트 클릭, 코멘트 좋아요, 오늘의 질문 투표
  • 코멘트 — 닉네임·본문·작성 시각, 적으신 경우 업종·직장(코멘트 옆에 공개)
  • 뉴스레터 링크로 오신 경우 구독자 표시 — 메일 링크에 붙은 회차 번호와 구독자 번호를 일방향 함수로 바꾼 값. 그 값만으로는 이메일을 알 수 없지만 저희가 대조할 수 있으므로 가명정보로 다룹니다. 이 표시와 함께 어느 회차의 어떤 글을 언제 열었는지가 남습니다
  • 웹에서 구독 신청 시 — 이메일, 이름, 출생연도, 관심분야, 하는 일, 광고성 정보 수신 동의 여부
  • 로그인한 경우 — 아래 회원(소셜 로그인)에 따로 적었습니다

로그인하지 않으면 이름·이메일·전화번호를 받지 않습니다(웹 구독 신청 제외).

이용 목적

  • 사이트 운영, 코멘트·반응·투표 기능 제공
  • 회차·글별 열람 수와 재방문 집계, 독자층 분석, 콘텐츠·발송 구성 개선
  • 오래 읽지 않은 구독자께 다시 안내할지 판단
  • 개인을 알아볼 수 없는 집계 통계 작성(광고 제안 등에 활용)
  • 오류·부정 이용 확인

개인정보를 제3자에게 제공하지 않습니다.

처리 위탁·국외 이전

  • Cloudflare, Inc.(미국) — 서버·데이터베이스 운영. 이 페이지에 적은 정보 전부. 정보통신망을 통해 상시 전송·저장
  • Amazon Web Services, Inc.(미국) — 알림 메일 발송. 이메일 주소·알림 내용. 알림이 생길 때 전송
  • (주)스티비(대한민국) — 뉴스레터 구독 관리·발송. 구독 신청 정보

보유 기간은 아래 「보관 기간」과 같습니다. 국외 이전을 원하지 않으시면 로그인하지 않거나 아래 연결 끄기를 요청하시면 됩니다. 다만 사이트 이용 자체에 필요한 처리는 거부할 수 없습니다.

보관 기간

  • 구독자 표시가 붙은 열람 기록 — 구독 기간 동안. 해지하시거나 연결 끄기를 요청하시면 낱개 기록을 지우고 합계만 남깁니다
  • 회원 정보 — 탈퇴할 때까지. 탈퇴하면 지체 없이 삭제합니다
  • 코멘트 — 작성자가 지우거나 삭제를 요청할 때까지
  • 그 밖의 익명 이용 기록 — 서비스 운영에 필요한 기간 동안

법령에 따라 보관해야 하는 경우는 그 기간 동안 보관합니다. 기간이 지나면 복구할 수 없는 방법으로 지웁니다.

쿠키

로그인한 분께만 로그인 유지용 쿠키 1개(60일)와 로그인 중 확인용 쿠키 1개(10분)를 씁니다. 방문 통계는 쿠키 없이 브라우저 저장소의 익명 번호로 셉니다. 브라우저 설정에서 쿠키·사이트 데이터를 지울 수 있고, 그러면 로그인과 이전 기록의 연결이 끊깁니다.

회원(소셜 로그인)

로그인은 선택입니다. 로그인하지 않아도 모든 글을 읽을 수 있습니다.

  • 수집 항목: 로그인 서비스(카카오·구글·네이버)의 고유 번호(해시로 저장), 이메일, 이름(별명), 프로필 사진 주소, 카카오·네이버에서 동의한 경우 연령대. 순살 안의 별명은 직접 정한 경우에만 저장합니다.
  • 함께 생기는 기록: 스크랩·반응·코멘트·투표, 팔로우한 회사·주제, 연결된 브라우저의 익명 번호, 가입·로그인 시각, 동의한 안내문 버전, 로그인 세션(해시), 알림 메일 설정.
  • 목적: 계정 표시와 여러 기기 동기화, 로그인 수단 연결, 답글·팔로우 알림(사이트 안·이메일 — 내 계정에서 끌 수 있음), 독자층 집계 통계, 문의 응대.
  • 동의 거부: 동의하지 않으면 로그인 기능만 쓸 수 없고, 다른 이용에는 제한이 없습니다.

남긴 글의 책임은 작성자에게 있습니다. 투자 권유·리딩방 유인·수익 보장·연락처 유도, 광고, 비방·모욕, 개인정보 노출, 도배 등 운영 원칙에 맞지 않는 글은 사전 통보 없이 숨기거나 검토 대기로 돌릴 수 있습니다.
