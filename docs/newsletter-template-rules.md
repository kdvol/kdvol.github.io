# 뉴스레터 템플릿 규칙 (chat ↔ code 동기화용)

뉴스레터 본문은 claude.ai 프로젝트 챗에서 쓰고, 웹사이트·파이프라인은 Claude Code에서
만진다. 이 파일은 **두 곳이 어긋나면 안 되는 것만** 적는다. 톤·문체·5개월치 편집 맥락은
챗 프로젝트가 원본이고 여기로 옮기지 않는다.

> **챗 프로젝트에 붙여넣을 때**: 아래 ①~④ 네 블록만 프로젝트 지침에 넣으면 된다. 나머지는 Code 쪽 참고용.

마지막 갱신: 2026-08-11

---

## 왜 대부분은 자동으로 따라오는가

빌드 스킬 Step 2가 **"헤더·푸터는 전일자에서 그대로 가져오기"** 이므로, 발행된 HTML
자체가 템플릿이다. 구조를 고칠 일이 있으면 **그날 발행분을 고쳐두면 다음 회차가
자동으로 물려받는다.** 별도 템플릿 파일을 관리하지 않는다.

→ 2026-08-11 발행분(`newsletters/2026/0811.html`)에 아래 ①②③이 이미 반영돼 있다.
   다음 회차는 이 파일을 베이스로 잡으면 그대로 따라온다.

---

## ① 로고 규격 — 원본을 다시 넣지 말 것

헤더·푸터 로고는 인라인 base64다. **원본 PNG(700×745, 각 19KB)를 그대로 넣으면 안 된다.**

| 위치 | 표시 크기 | 넣을 크기 | base64 |
|------|----------|----------|--------|
| 헤더 | `height:36px` | **68×72** | 약 2.4KB |
| 푸터 | `height:24px` | **45×48** | 약 1.4KB |

전일자 파일에서 `<img src="data:image/png;base64,...">`를 **통째로 복사**하면 자동으로
맞는다. 새로 인코딩해야 한다면 Code 쪽에서:

```bash
python3 scripts/shrink_logos.py newsletters/2026/MMDD.html
```

## ② 우상단 링크 — 두 개

```html
<tr><td class="hello-web" style="text-align:right;"><a href="https://soonsal.com/newsletters/2026/MMDD.html">웹에서 보기 &#8599;</a> <span style="color:#ddd;">·</span> <a href="https://soonsal.com/newsletters/">지난 호 &#8599;</a></td></tr>
```

"웹에서 보기"는 회차 URL(날짜 갈아끼우기), "지난 호"는 아카이브 인덱스 `/newsletters/`로
고정이다. 웹으로 넘어온 독자를 아카이브까지 이어준다.

## ③ 인사말 아카이브 줄

인사말 CTA 마지막에 한 줄. 오늘 다룬 회사의 과거 아카이브로 잇는다.

```html
<span style="margin-top:9px;">엔비디아 얘기, 오늘이 처음 아님 &#8594; <a href="https://soonsal.com/wiki/nvidia.html">순살이 다룬 엔비디아 102건</a></span>
```

**만드는 법 (챗에서 매 회차 자동):**

HTML 조립 단계에서 아래를 `web_fetch` 한다. 6KB, 하루 한 번이면 충분하다.

```
https://soonsal.com/api/entities.json
```

응답에 `usage`(사용법), `template`(문구 틀), `url_form`, `entities`(94개, 회사·인물만)가
들어 있다. `entities`는 `[이름, 별칭목록, 건수, 슬러그]` 배열이다.

1. 오늘 **인사말 헤드라인이 가리키는 회사/인물**을 이름 또는 별칭에서 찾는다
2. `url_form`의 `{slug}`를 채워 URL을 만든다
3. `template`의 `{name}` `{url}` `{count}`를 채워 CTA 마지막에 붙인다

규칙:

- **헤드라인이 가리키는 쪽**으로 건다. 아카이브가 제일 두꺼운 항목이 아니다.
  (0811: 헤드라인은 엔비디아 102건, 목록 1순위는 오픈AI 119건 → 엔비디아로 감)
- 회사·인물만 들어 있다. 원유·금·국채 같은 자산과 규제기관은 애초에 빠져 있다 —
  "원유 얘기, 오늘이 처음 아님"은 말이 안 되기 때문
- **건수를 지어내지 않는다.** 목록에 없으면 **줄을 넣지 않는다.** 빈 줄이 억지 링크보다 낫다
- 이 파일은 매 배포마다 갱신된다. 캐시된 옛 숫자를 쓰지 말고 그때그때 받는다

Code 쪽에서 후보를 눈으로 볼 때:

```bash
python3 scripts/archive_line.py 2026-08-11          # 후보 목록 + 1순위
python3 scripts/archive_line.py 2026-08-11 nvidia   # 헤드라인에 맞춰 지정
```

### 요일 로테이션을 쓰지 않는 이유

월=웹, 화=인스타… 식으로 요일마다 채널을 돌리는 안을 검토했다가 접었다. 그날 내용과
무관해서 광고 줄로 읽히고, 몇 주면 독자 눈이 그 자리를 건너뛴다. 아카이브 줄은 방금
읽은 내용의 연장이라 "더 보기"로 읽히고, 링크가 닿는 웹사이트에 텔레그램 플로팅 버튼과
인스타 유도 블록이 이미 있어서 **채널 분배는 웹사이트가 대신한다.** 메일에서는 링크
하나만 내보낸다.

인스타·텔레그램을 직접 걸어야 할 때는 요일이 아니라 **그날 실제로 뭐가 나갔는지**로
판단한다. 카드뉴스가 나간 날만 인스타, 크립토 회차가 나간 날만 크립토 채널.

## ④ 용량 — Gmail 102KB

Gmail은 본문이 **102KB를 넘으면 잘라내고** "전체 메시지 보기"로 접는다. 잘리면 푸터·
수신거부 링크까지 안 보인다.

- 2026-08-05 회차가 **116KB로 실제 초과**했다. 하필 세일즈포스 광고 회차였다.
- 로고를 줄이기 전에는 모든 회차가 96~100KB로 한도 2~6KB 앞에 붙어 있었다.
- ①을 지키면 **약 54KB**로 떨어진다. 여유 48KB.

빌드 감사에 넣을 것: **완성 HTML 파일 크기 < 100KB**. 넘으면 인라인 이미지부터 의심한다.
