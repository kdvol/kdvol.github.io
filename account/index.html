내 계정

로그인하면 스크랩·댓글·알림이 폰과 PC 에서 같이 보여요.

무엇을 받나요? (이메일·이름·사진)
  • 로그인한 서비스(카카오·구글·네이버)가 주는 고유 번호(암호화해 저장), 이메일, 이름(별명), 프로필 사진 주소, 카카오·네이버에서 동의한 경우 연령대(예: 30대).
  • 목적: 어느 계정으로 로그인했는지 보여 주기, 카카오·구글·네이버 로그인을 한 계정으로 묶기, 스크랩·반응·한마디를 계정에 저장해 여러 기기에서 보여 주기, 내 댓글에 답글이 달리거나 팔로우한 회사·주제가 브리핑에 나오면 알림(사이트·이메일, 내 계정에서 끌 수 있음), 독자층 집계 통계, 계정 문의 응대.
  • 보관: 탈퇴할 때까지. 탈퇴하면 지체 없이 지워요.
  • 저장·발송: Cloudflare(데이터 저장), Amazon Web Services(알림 메일 발송) — 처리 위탁·미국.
  • 동의하지 않으면 로그인만 쓸 수 없고, 다른 이용에는 제한이 없어요.
